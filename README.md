# Microsoft AI Lab

**A hands-on laboratory for exploring Microsoft technologies, artificial intelligence, and software engineering.**

Microsoft AI Lab is an individual learning and project portfolio focused on building practical, documented experiments with the Microsoft ecosystem.

The goal is not to collect technologies for their own sake. Each project should solve a clear problem, explain its technical decisions, and leave behind something that others can reproduce or learn from.

## Focus areas

- **Artificial Intelligence:** LLM applications, AI agents, retrieval-augmented generation (RAG), evaluation, and responsible AI.
- **Software Engineering:** APIs, backend services, testing, architecture, and maintainable code.
- **Microsoft ecosystem:** Azure, Microsoft Foundry, Microsoft Learn, .NET, Semantic Kernel, and other relevant tools.
- **Learning in public:** concise technical notes, reproducible experiments, and lessons learned.

## Projects

Projects will be added as they become sufficiently developed and documented. Each project should ideally include:

1. A problem statement and intended users.
2. A clear explanation of the approach and architecture.
3. Setup instructions and reproducible examples.
4. Tests or an evaluation method appropriate to the project.
5. Limitations, risks, and possible next steps.

See [projects/README.md](projects/README.md) for the project index.

## Working principles

- Build first, document decisions, and validate results.
- Prefer small, complete experiments over unfinished collections of tutorials.
- Be transparent about limitations and what has or has not been tested.
- Protect credentials and personal data. Never commit API keys, tokens, or secrets.
- Use Microsoft technologies when they add real value to the project.

## Language

The repository may contain documentation in **English and Portuguese (Brazil)**. Code, filenames, and primary project documentation will generally use English to make the work accessible to a broader technical audience.
