# Projects

This directory contains independent, hands-on projects developed as part of Microsoft AI Lab.

Each project should have its own directory and README with:

- **Problem:** what is being solved and for whom.
- **Approach:** how the solution works.
- **Technology:** tools and services used, with reasons for choosing them.
- **Run locally:** setup and execution instructions.
- **Evaluation:** tests, examples, or measurable criteria.
- **Limitations:** known issues, risks, and next steps.

No project is considered complete merely because a demo runs. Reproducibility and honest documentation matter.
