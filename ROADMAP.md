# Roadmap

This roadmap is intentionally iterative. Priorities may change as experiments reveal better questions or tools.

## Phase 1 — Foundations

- [ ] Set up the repository conventions and documentation.
- [ ] Review the fundamentals of Azure and Microsoft AI services.
- [ ] Complete a small, reproducible experiment using a Microsoft technology.
- [ ] Document setup, costs or free-tier constraints, and limitations.

## Phase 2 — Applied AI

- [ ] Build a focused LLM application.
- [ ] Explore retrieval-augmented generation (RAG) with traceable sources.
- [ ] Add a basic evaluation strategy instead of relying only on subjective outputs.
- [ ] Document privacy, security, and failure cases.

## Phase 3 — AI agents and engineering

- [ ] Build an agentic workflow with explicit tools and boundaries.
- [ ] Add logging, error handling, and human review where appropriate.
- [ ] Compare design choices and document trade-offs.

## Phase 4 — Share and improve

- [ ] Publish complete project write-ups.
- [ ] Collect feedback from developers and learners.
- [ ] Improve projects based on reproducible issues and useful feedback.

## Prioritization criteria

A project should be prioritized when it has a clear problem, a manageable scope, a meaningful technical learning outcome, and a way to demonstrate whether it works.
